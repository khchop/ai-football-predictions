## Tech Debt

### Phase 71: AI Content & FAQ Generation
- No SQL migration file in `drizzle/` directory — table created via TypeScript migration script (`scripts/migrate-team-content.ts`). Different pattern from `drizzle/0016_add_team_indexes.sql`. Non-blocking (table exists in production).
- Rate limit math shows 30 req/min theoretical vs OpenRouter's ~20 req/min limit. Works in practice because serial execution + LLM generation latency (~5-10s per call) keeps actual rate well below limit.

### Phase 68: Routes, SEO & Basic Pages
- ISR `revalidate=300` was added in 68-02 then removed in 70 (incompatible with Next.js 16 PPR/cacheComponents). Caching now handled at Redis data layer with tag-based invalidation.
- Canonical URL strategy for overlap between /leaderboard and /teams/[slug] pages not yet decided.

### General
- `getAllTeamSlugs()` exported from teams.ts but not yet consumed (available for future `generateStaticParams`).
- Human verification items across all 5 phases (visual UX, Schema.org validation, cron triggers, rate limiting compliance) need post-deployment testing.

**Total: 6 non-blocking tech debt items across 3 categories.**
