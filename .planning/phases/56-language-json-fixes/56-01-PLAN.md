Step 4 -- Check for models needing combined variants:
- If any model needs BOTH English enforcement AND JSON strict (language + parse issues), check if a combined variant ENGLISH_JSON_STRICT exists in prompt-variants.ts
- If not and 2+ models need it, create the combined variant following the ENGLISH_THINKING_STRIPPED pattern:
  ```
  ENGLISH_JSON_STRICT = 'english-json-strict'
  ```

  ```
  '\n\nCRITICAL: Respond ONLY in English. Do not output Chinese or any other language.\n\n' +
  'OUTPUT FORMAT - CRITICAL:\n' +
  '- Return ONLY valid JSON\n' +
  '- No explanations before or after the JSON\n' +
  '- No markdown code blocks\n' +
  '- No natural language\n' +
  '- Just the raw JSON object'
  ```

- For any model identified as needing English enforcement that does not have it, add promptVariant: PromptVariant.ENGLISH_ENFORCED to its PromptConfig
- Do NOT change models that already work (no preemptive fixes per research Pitfall 1)
- Do NOT remove existing handlers (e.g., keep GLM-4.7's EXTRACT_JSON handler)
- Do NOT modify response_format: {type: "json_object"} in base.ts (per research Pitfall 3)
