**Default export page component (async Server Component):**
1. Await `params` to get `slug`
2. `getTeamBySlug(slug)` — if not found, call `notFound()`

5. Build `teamSchema` via `buildSportsTeamSchema(team, stats)`
6. Build `breadcrumbSchemaItems` via `buildBreadcrumbSchema([{ name: 'Home', url: BASE_URL }, { name: 'Teams', url: \`${BASE_URL}/teams\` }, { name: team.id, url: \`${BASE_URL}/teams/${team.slug}\` }])`
7. Combine in `@graph`: `{ '@context': 'https://schema.org', '@graph': [teamSchema, breadcrumbSchemaItems] }`
8. Build visual breadcrumbs via `buildTeamBreadcrumbs(team.id, team.slug)`
9. Look up competition via `getCompetitionById(team.league)`
