**Step 2: Create the TeamConfig interface and TEAMS array.**

```typescript
export interface TeamConfig {
  id: string;           // Canonical DB name exactly as stored (e.g., "Manchester City")
  slug: string;         // URL slug (e.g., "manchester-city")
  aliases?: string[];   // Known variants (e.g., ["Man City", "Man. City"])
  league: string;       // Competition ID from competitions.ts (e.g., "epl", "laliga")
}
```

For each distinct team name from the DB:
- `id` = exact string from database (case-sensitive, must match exactly)
- `slug` = lowercase, hyphenated version of the name. For slug collisions across leagues, append league suffix (e.g., "racing-argentina" vs "racing-france")
- `aliases` = only add if known abbreviations/variants exist. Common patterns: "Man City"/"Manchester City", "Atletico Madrid"/"Atletico de Madrid", "Inter"/"Inter Milan"/"FC Internazionale"
- `league` = map to competition ID from competitions.ts

**Step 3: Detect and resolve slug collisions.**

**Step 5: Add a validation function** for use by audit scripts:
```typescript
export function validateTeamMapping(dbTeamNames: string[]): { mapped: string[], unmapped: string[] } {
  const mappedIds = new Set(TEAMS.map(t => t.id));
  const mappedAliases = new Set(TEAMS.flatMap(t => t.aliases || []));
  const mapped = dbTeamNames.filter(n => mappedIds.has(n) || mappedAliases.has(n));
  const unmapped = dbTeamNames.filter(n => !mappedIds.has(n) && !mappedAliases.has(n));
  return { mapped, unmapped };
}
```

import { matches } from '@/lib/db/schema';
import { getTeamByIdOrAlias, validateTeamMapping } from '@/lib/football/teams';
import { sql } from 'drizzle-orm';

async function main() {
  const db = getDb();
  const result = await db.execute(sql`
    SELECT DISTINCT name FROM (
      SELECT home_team AS name FROM matches
      UNION
      SELECT away_team AS name FROM matches
    ) t ORDER BY name
  `);
  const dbTeamNames = result.rows.map((r: any) => r.name as string);
  const { unmapped } = validateTeamMapping(dbTeamNames);

  if (unmapped.length === 0) {
    console.log(`✓ All ${dbTeamNames.length} DB team names resolve correctly.`);
    process.exit(0);
  } else {
    console.error(`✗ ${unmapped.length} unmapped team names:`);
    unmapped.forEach(n => console.error(`  - ${n}`));
    process.exit(1);
  }
}

main().catch(e => { console.error(e); process.exit(1); });

-- B-tree indexes for exact string matching on team columns
-- These optimize WHERE home_team = 'X' and WHERE away_team = 'X' queries

CREATE INDEX IF NOT EXISTS idx_matches_home_team ON matches(home_team);

Use `IF NOT EXISTS` for idempotency. Do NOT use `CONCURRENTLY` in the migration file (Drizzle migrations run in transactions; CONCURRENTLY cannot run inside a transaction). The `CONCURRENTLY` approach is for manual production execution only — note this in a comment.
