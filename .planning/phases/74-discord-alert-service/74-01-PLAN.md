Create `src/lib/notifications/discord.ts` with the following:

1. **Core send function** `sendDiscordAlert(embed: DiscordEmbed): Promise<void>`:
   - Read webhook URL from `process.env.DISCORD_WEBHOOK_URL` (not from env.ts getter to avoid throwing)
   - If URL is not set, log debug message and return silently (graceful degradation)
   - POST to webhook URL with `Content-Type: application/json` body: `{ embeds: [embed] }`
   - Use native `fetch()` (no external library needed)
   - Wrap in try/catch -- log errors via `loggers.discord` but never throw (fire-and-forget, must not break pipeline)
   - Set a 5-second timeout using `AbortSignal.timeout(5000)`

2. **Auto-disable alert** `sendAutoDisableAlert(params: { modelId: string; displayName: string; consecutiveFailures: number; failureReason: string; lastSuccessAt: string | null }): Promise<void>`:
   - Color: `0xFF0000` (red)
   - Title: "Model Auto-Disabled"
   - Fields:
     - Model: `{displayName}` (`{modelId}`)
     - Consecutive Failures: `{consecutiveFailures}`
     - Error: `{failureReason}` (truncated to 200 chars)
     - Last Success: `{lastSuccessAt}` or "Never"
     - Suggested Action: "Check model status on OpenRouter. If persistent, consider archiving with `UPDATE models SET archived = true WHERE id = '{modelId}'`"
   - Timestamp: ISO string of current time
   - Footer: "Auto-Disable Alert | Threshold: 5 failures"

3. **Regression alert** `sendRegressionAlert(regressions: Array<{ modelId: string; displayName: string; previousSuccessRate: number; currentSuccessRate: number; drop: number; severity: 'warning' | 'critical' }>): Promise<void>`:
   - If no regressions, return silently
   - Color: `0xFF0000` for any critical, `0xFFA500` (orange) for warnings only
   - Title: "Model Regression Detected" with count
   - For each regression (up to 10), add a field:
     - Name: `{severity emoji} {displayName}`
     - Value: `{previousSuccessRate.toFixed(1)}% -> {currentSuccessRate.toFixed(1)}% (drop: {drop.toFixed(1)}%)`
   - Severity emojis: critical = "🔴", warning = "🟡"
   - Suggested Action field: "Review model health in admin dashboard at /admin"
   - Timestamp: ISO string of current time
   - Footer: "Regression Alert | Threshold: >10% drop"

4. **Type definitions** (inline in the file, no separate types file needed):
   - `DiscordEmbed` interface: `{ title: string; description?: string; color: number; fields: Array<{ name: string; value: string; inline?: boolean }>; timestamp?: string; footer?: { text: string } }`

5. **Add to env.ts**: Add `DISCORD_WEBHOOK_URL: process.env.DISCORD_WEBHOOK_URL,` in the optional section (after REDIS_URL line ~73). Do NOT add it to REQUIRED_ENV_VARS -- it must be optional.

1. **Auto-disable alert in `src/lib/db/queries.ts`** -- in the `recordModelFailure` function:
   - After the existing log at line ~896 (`loggers.db.warn({ modelId, consecutiveFailures... }, 'Model auto-disabled...')`)
   - Add: import `sendAutoDisableAlert` from `@/lib/notifications/discord`
   - Call `sendAutoDisableAlert()` with the model data. Use fire-and-forget pattern (no await, catch errors):
   ```typescript
   sendAutoDisableAlert({
     modelId,
     displayName: modelId, // modelId is the best we have in this context
     consecutiveFailures: updated.consecutiveFailures || 0,
     failureReason: reason.substring(0, 200),
     lastSuccessAt: null, // Not available in this query context
   }).catch(() => {}); // Fire and forget, errors logged internally
   ```
   - IMPORTANT: Do NOT await the Discord call -- it must not slow down the failure recording path. The `.catch(() => {})` prevents unhandled promise rejections. The discord service already logs errors internally.
   - To get displayName and lastSuccessAt, query the model BEFORE the update (add a SELECT for model.displayName and model.lastSuccessAt where id = modelId, only when autoDisabled transitions to true). This keeps the alert informative:
   ```typescript
   if (updated?.autoDisabled && isModelSpecific) {
     // Existing log...

     // Get display name for Discord alert (cheap single-row query)
     const modelInfo = await db.select({ displayName: models.displayName, lastSuccessAt: models.lastSuccessAt }).from(models).where(eq(models.id, modelId)).limit(1);

     sendAutoDisableAlert({
       modelId,
       displayName: modelInfo[0]?.displayName || modelId,
       consecutiveFailures: updated.consecutiveFailures || 0,
       failureReason: reason.substring(0, 200),
       lastSuccessAt: modelInfo[0]?.lastSuccessAt || null,
     }).catch(() => {});
   }
   ```
