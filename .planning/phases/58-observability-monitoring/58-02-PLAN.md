**API Endpoint: `src/app/api/admin/model-health/route.ts`**

Create a GET endpoint following the exact pattern from `/api/admin/pipeline-health/route.ts`:
1. Rate limit check using `checkRateLimit` with `RATE_LIMIT_PRESETS.admin`
2. Admin auth using `requireAdminAuth`
3. Error handling with `sanitizeError`

The endpoint supports two modes via query params:
- No params: Returns summary for all models via `getAllModelHealthSummary()`
- `?modelId=xxx`: Returns detailed trends for one model via `getModelHealthTrends(modelId)`

Response shape (summary mode):
```json
{
  "timestamp": "ISO string",
  "summary": {
    "totalModels": 35,
    "healthy": 29,
    "warning": 3,
    "critical": 3
  },
  "models": [
    {
      "modelId": "...",
      "displayName": "...",
      "provider": "...",
      "successRate7d": 95.2,
      "successRate30d": 92.1,
      "totalAttempts7d": 140,
      "lastFailure": "2026-02-07T...",
      "failureCategory": "timeout",
      "status": "healthy"
    }
  ]
}
```

Response shape (detail mode):
```json
{
  "timestamp": "ISO string",
  "modelId": "...",
  "trends": {
    "current": { "successRate": 95.2, "lastFailure": "...", "failureCategory": "..." },
    "days7": { "successRate": 95.2, "attempts": 140, "dailyData": [...] },
    "days30": { "successRate": 93.1, "attempts": 580, "dailyData": [...] },
    "days90": { "successRate": 91.8, "attempts": 1720, "dailyData": [...] }
  }
}
```

Import from `@/lib/db/queries/model-stats` (the module created in 58-01).

**Component: `src/components/admin/model-health-cards.tsx`**

Create a `'use client'` component that displays per-model health. Follow the visual style of existing admin components (model-health-table.tsx, fallback-metrics.tsx).

Structure:
1. **Summary bar** at top: 4 stat cards showing total models, healthy count (green), warning count (yellow), critical count (red). Use `Activity`, `CheckCircle`, `AlertTriangle`, `XCircle` icons from lucide-react.

2. **Model cards grid**: Display each model as a card. Cards show:
   - Model display name and provider badge
   - 7-day success rate as large number with color coding (green >= 90%, yellow >= 80%, red < 80%)
   - 30-day success rate (smaller, for context)
   - Last failure timestamp (relative, e.g., "2h ago")
   - Failure category badge (timeout/parse/api/language)
   - Mini sparkline or indicator showing trend direction

3. **Detail modal/expansion**: When a model card is clicked, show:
   - Recharts LineChart with success rate over time (using `SuccessRateTrend` pattern from research)
   - Time window selector (7d / 30d / 90d tabs)
   - Reference line at 90% threshold (green dashed)
   - Tooltip showing date, success rate %, and attempt count

Use Recharts imports: `LineChart, Line, XAxis, YAxis, CartesianGrid, Tooltip, ResponsiveContainer`
Use date-fns: `format, parseISO, formatDistanceToNow`
Use existing `cn` utility from `@/lib/utils`

The component accepts a `password` prop (string) for authenticated API calls, following the pattern in `admin-dashboard.tsx` where password is passed to child components.
