  <action>
    Create scripts/diagnostic/generate-coverage-report.ts that generates a comprehensive
    Phase 57 coverage assessment from diagnostic results. This script:

    1. Reads diagnostic result files from src/__tests__/diagnostic-results/raw-responses/
       (one JSON file per model, created by npm run diagnose)
    2. Imports MODEL_FALLBACKS from src/lib/llm/index.ts for fallback status
    3. Imports ALL_PROVIDERS from src/lib/llm for full model inventory
    4. For each model result, classifies into:
       - PASS: Valid prediction JSON produced
       - FAIL-FIXABLE: Failed but has fallback or config that could help
       - FAIL-UNFIXABLE: Failed, no fallback available, all configs applied
       - SKIP: Model was not tested (API key missing, etc.)
    5. Generates markdown report with sections:
       a. Executive Summary: Overall success rate, pass/fail counts, target comparison
       b. Model Coverage Matrix: Table with columns:
          Model ID | Provider | Status | Fallback | Config | Category | Notes
       c. Failure Analysis: For each failing model:
          - Failure category (from categorizeFailure)
          - Root cause analysis (from raw response)
          - Severity: CRITICAL (core model), HIGH (premium), MEDIUM (budget), LOW (niche)
          - Mitigation plan (existing config, auto-disable, accept)
       d. Unfixable Models: Models with SKIP status and full rationale per research template
       e. Recommendations: Next steps based on results
    6. Writes report to src/__tests__/diagnostic-results/reports/coverage-assessment.md
    7. Prints summary to stdout

    If no diagnostic results exist yet (user hasn't run `npm run diagnose`), the script
    should print a clear message: "No diagnostic results found. Run 'npm run diagnose' first."
    and exit 0.

    Follow existing patterns in scripts/diagnostic/generate-report.ts for markdown generation
    style. Use the unfixable model documentation template from 57-RESEARCH.md as format guide.
  </action>
