**1. `getTeamUpcomingWithPredictions()`:**

Fetches upcoming (scheduled) matches for a team with aggregated prediction distribution from all AI models.

```typescript
export interface UpcomingMatchWithPredictions {
  matchId: string;
  homeTeam: string;
  awayTeam: string;
  homeTeamLogo: string | null;
  awayTeamLogo: string | null;
  kickoffTime: string;
  competitionId: string;
  slug: string | null;
  isHome: boolean;
  predictionCount: number;
  homeWinPct: number;    // percentage of models predicting home win
  drawPct: number;       // percentage predicting draw
  awayWinPct: number;    // percentage predicting away win
  avgPredictedHome: number;  // average predicted home score
  avgPredictedAway: number;  // average predicted away score
}
```

Implementation:
- Query `matches` WHERE `(homeTeam = teamName OR awayTeam = teamName) AND status = 'scheduled'`
- LEFT JOIN `predictions` ON `predictions.matchId = matches.id` to get all model predictions for each match
- Use SQL aggregation to compute: `COUNT(predictions.id)` as predictionCount, `SUM(CASE WHEN predicted_home > predicted_away THEN 1 ELSE 0 END)` for home win count, similarly for draw and away win
- Calculate percentages in TypeScript: `homeWinPct = Math.round((homeWinCount / predictionCount) * 100)` etc.
- Also compute `AVG(predicted_home)` and `AVG(predicted_away)` for average predicted scoreline
- ORDER BY `kickoffTime ASC` (soonest first), LIMIT 5
- Handle zero predictions gracefully (all pcts = 0, predictionCount = 0)

Import `predictions` from `@/lib/db` alongside existing imports.

**2. `getTeamRecentWithAccuracy()`:**

Fetches recent finished matches with per-match prediction accuracy (how many models got the tendency correct).

```typescript
export interface RecentMatchWithAccuracy {
  matchId: string;
  homeTeam: string;
  awayTeam: string;
  homeTeamLogo: string | null;
  awayTeamLogo: string | null;
  homeScore: number | null;
  awayScore: number | null;
  kickoffTime: string;
  competitionId: string;
  slug: string | null;
  isHome: boolean;
  result: 'W' | 'D' | 'L';  // from team's perspective
  predictionCount: number;
  correctPredictions: number;  // models that got tendency right
  accuracyPct: number;        // correctPredictions / predictionCount * 100
  exactScoreCount: number;    // models that got exact score
}
```

Implementation:
- Query `matches` WHERE `(homeTeam = teamName OR awayTeam = teamName) AND status = 'finished'`
- LEFT JOIN `predictions` ON `predictions.matchId = matches.id AND predictions.status = 'scored'`
- Aggregate per match: `COUNT(predictions.id)`, `SUM(CASE WHEN tendency_points > 0 THEN 1 ELSE 0 END)` as correctPredictions, `SUM(CASE WHEN exact_score_bonus = 3 THEN 1 ELSE 0 END)` as exactScoreCount
- GROUP BY all match columns
- Compute `result` in TypeScript from scores and isHome flag (same logic as `getTeamFormGuide`)
- Compute `accuracyPct = Math.round((correctPredictions / predictionCount) * 100)` with zero-division guard
- ORDER BY `kickoffTime DESC` (most recent first), LIMIT 10

**3. `getTeamAccuracyTrend()`:**

Fetches weekly aggregated model accuracy for a team over time (for the line chart).

```typescript
export interface AccuracyTrendPoint {
  weekStart: string;  // ISO date of week start (Monday)
  matchCount: number;
  predictionCount: number;
  correctPredictions: number;
  accuracyPct: number;
}
```

Implementation:
- Query: SELECT `DATE_TRUNC('week', matches.kickoff_time)` as weekStart, COUNT DISTINCT matches, COUNT predictions, SUM correct tendencies
- WHERE team matches (home or away), status = 'finished', predictions.status = 'scored'
- JOIN predictions on matchId, JOIN matches
- GROUP BY week
- ORDER BY weekStart ASC
- Limit to last 20 weeks (enough data points for a meaningful chart without performance issues per Recharts pitfall in research)
- Calculate accuracyPct in TypeScript

All three functions should be exported and use the existing Drizzle ORM patterns (sql tagged templates for aggregation, typed returns).
