**In `src/lib/db/schema.ts`**, add a new `teamContent` table AFTER the `matchContent` table definition (around line 537). Follow the exact same patterns as `matchContent` and `blogPosts`:

```typescript
// AI-generated team analysis and FAQ content for SEO/GEO
export const teamContent = pgTable('team_content', {
  id: text('id').primaryKey(), // UUID
  teamName: text('team_name').notNull().unique(), // Canonical team name from teams.ts

  // AI-generated analysis prose (200-250 words)
  analysis: text('analysis'),
  analysisGeneratedAt: text('analysis_generated_at'),

  // AI-generated FAQ content (JSON array of {question, answer} pairs)
  faqContent: text('faq_content'), // JSON string
  faqGeneratedAt: text('faq_generated_at'),

  // AI generation metadata
  generatedBy: text('generated_by'), // Model name (e.g., 'deepseek/deepseek-chat-v3.1')
  totalTokens: integer('total_tokens').default(0),
  totalCost: text('total_cost').default('0'), // USD string for precision

  createdAt: text('created_at').default(sql`now()`),
  updatedAt: text('updated_at').default(sql`now()`),
}, (table) => [
  index('idx_team_content_team_name').on(table.teamName),
]);

export type TeamContent = typeof teamContent.$inferSelect;
export type NewTeamContent = typeof teamContent.$inferInsert;
```

Key decisions:
- Use `text` types for timestamps (matches existing pattern in matchContent, not timestamp)
- `teamName` is unique (one content row per team, upsert on conflict)
- Separate `analysisGeneratedAt` and `faqGeneratedAt` so they can be generated independently
- `totalCost` as text string for precision (matches modelUsage pattern)

**Create `src/lib/db/queries/team-content.ts`** with three functions:

1. `getTeamContent(teamName: string): Promise<TeamContent | null>` — Fetches team content by name with Redis caching (5 min TTL). Import `teamContent` from `@/lib/db` (the barrel re-exports schema). Use `withCache` from `@/lib/cache/redis` with key `team-content:${teamName}`.

2. `upsertTeamAnalysis(teamName, analysis, metadata)` — Upserts analysis text + generation metadata. Uses `onConflictDoUpdate` targeting `teamContent.teamName`. After upsert, delete the Redis cache key for this team.

3. `upsertTeamFAQs(teamName, faqs: FAQItem[], metadata)` — Upserts FAQ JSON + generation metadata. Same conflict resolution pattern. Stores `JSON.stringify(faqs)` in `faqContent`.

Import `FAQItem` type from `@/lib/seo/schemas` (already exported there). Import `v4 as uuidv4` from `uuid`. Use `getDb` and `teamContent` from `@/lib/db`. Use `eq` from `drizzle-orm`.

**Function 1: `generateTeamAnalysis(teamName: string): Promise<void>`**

Steps:
1. Import and call `getTeamStats(teamName)` from `@/lib/db/queries/team-stats`
2. Import and call `getTeamFormGuide(teamName, 5)` from `@/lib/db/queries/team-stats`
3. Import and call `getTeamModelLeaderboard(teamName, { timePeriod: 'all', limit: 5 })` from `@/lib/db/queries/team-stats`
4. Check: if `stats.totalMatches < 5`, log warning and return early (skip generation for teams with insufficient data)
5. Build prompt with team data. System prompt: `'You are a football analyst writing club analysis for betting enthusiasts who use AI-powered prediction models.'`
6. User prompt template (fill with actual data):
   - Team name, total matches, W/D/L record, goals F/A, goal difference
   - Recent form (last 5 as W/D/L string)
   - Top 3-5 performing AI models for this team with accuracy percentages
   - Average model accuracy across all models
   - Instructions: Write 3-4 paragraphs (200-250 words). Include form analysis, goal patterns, AI model performance for this team, notable patterns.
   - OUTPUT FORMAT: Plain text only, no HTML. Use natural line breaks.
   - CRITICAL ANTI-HALLUCINATION: "Do NOT mention player names, injuries, managers, transfer rumors, or league table positions unless explicitly provided above. Only use the statistics given."
7. Call `generateTextWithOpenRouter(systemPrompt, prompt, 0.7, 1000)`
8. Sanitize with `sanitizeContent()`, validate with `validateNoHtml()`
9. Use `validateGeneratedContent()` — copy the function locally from match-content.ts or import if exported. Accept 'team-analysis' as content type with min length 150.
10. Call `upsertTeamAnalysis()` from `@/lib/db/queries/team-content` with the analysis, model name from `CONTENT_CONFIG.model`, token usage, and cost estimate.

**Function 2: `generateTeamFAQs(teamName: string): Promise<void>`**

Steps:
1. Fetch same data as analysis (stats, form guide, top models) + call `getOverallStats()` from `@/lib/db/queries` for active model count
2. Check: if `stats.totalMatches < 5`, return early
3. Build prompt requesting exactly 5-7 FAQ pairs as JSON array. Include:
   - Required questions (in order):
     1. What is {team}'s win-loss record?
     2. Which AI model performs best for {team}?
     3. How accurate are AI predictions for {team}?
     4. What is {team}'s recent form?
     5. How many AI models predict {team} matches?
     6-7. Optional: home/away record, goal scoring patterns
   - Each answer: 2-3 sentences, factual, uses ONLY provided data
   - Include specific model names from the leaderboard data
   - Return valid JSON array with "question" and "answer" fields
4. System prompt: `'You are an SEO expert generating FAQ content for AI-powered football prediction pages. Return valid JSON only.'`
5. Call `generateWithOpenRouter<FAQItem[]>(systemPrompt, prompt, 0.7, 2000)`
6. Validate: check `Array.isArray`, length > 0, slice to max 7
7. For each FAQ: sanitize question and answer, validate no HTML, check min lengths (question >= 10, answer >= 20)
8. Call `upsertTeamFAQs()` with sanitized FAQs array, metadata

Import `FAQItem` from `@/lib/seo/schemas` (not from match-content.ts to avoid coupling).
