**Context:** `match-card.tsx` is a `'use client'` component. The ENTIRE card is wrapped in a `<Link>` to the match page (line 92-100). Team names are `<p>` tags inside this Link (lines 172-181 for home, lines 220-230 for away). Adding Link components inside another Link creates nested `<a>` tags (invalid HTML, accessibility violation).

**Approach:** Convert team name `<p>` tags to `<a>` tags (not `<Link>`) with `onClick={(e) => { e.preventDefault(); e.stopPropagation(); window.location.href = teamUrl; }}`. WAIT -- this loses Next.js client-side navigation benefits.

**Better approach:** Use the same overlay pattern as 70-01. Replace the outer `<Link>` with a `<div>` and use an invisible overlay `<a>` for the match URL, then team names become real `<Link>` components above the overlay.

**However**, this component is heavily used across the site and the outer Link provides Next.js prefetching for match pages. Changing to overlay anchor loses prefetch.

**Best approach for match-card.tsx:** Since this is a `'use client'` component, use `next/link` for team names and `onClick={e => e.stopPropagation()}`. The browser will handle the click on the inner link without propagating to the outer link. While technically nested `<a>` is invalid HTML, React/Next.js handles this correctly at runtime with event handling. This is the pattern recommended in the research and used by major sites. The accessibility concern is mitigated by the `stopPropagation` -- screen readers will announce both links separately.

**Actually, the cleanest solution:** Keep the outer `<Link>` but use the `onClickCapture` pattern on team names. Or, simply use a small refactor: make the team name a `<span>` with an `onClick` that does `router.push()`. But this loses right-click/cmd-click behavior.

**Final decision: Use the overlay pattern.** Replace the outer `<Link>` wrapper with a plain `<div>`, add an invisible overlay anchor (plain `<a>` with `href`) for the match URL, and make team names real `<Link>` components. The outer `<div>` keeps all the existing styling. The overlay anchor enables all interaction patterns (right-click, cmd-click). Team name Links sit above the overlay.
