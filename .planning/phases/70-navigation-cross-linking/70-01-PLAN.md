**Simplest valid approach -- use `<span>` with nested anchor workaround:**

Actually, reviewing the HTML spec more carefully: the real issue is `<a>` inside `<a>`. However, with the current code structure, the `<Link>` wraps the entire `<Card>`. The team names are rendered as `<span>` elements INSIDE the card. We can convert the team name spans into Links and the browser will handle this correctly in practice (modern browsers hoist the inner link), but it's technically invalid HTML.

**Recommended approach: Refactor to use CSS pointer pattern instead of wrapping Link.**

For both files, change the pattern from:
```
<Link href={matchUrl}><Card>...</Card></Link>
```
To:
```
<Card className="relative">
  <a href={matchUrl} className="absolute inset-0 z-0" aria-label="View match details" />
  ...team name Links with relative z-10...
</Card>
```

This uses an invisible overlay anchor for the card click, and team name Links sit above it with higher z-index.
